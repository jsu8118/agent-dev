# Incident INC-P2-0419 — Repeated seal failures in hydrostatic test; O-ring groove cracks

| Field | Value |
|---|---|
| Plant | P2 Lakeside |
| Date | 2026-08-19 |
| Reported by | S. Brandt, Test cell lead; K. Yamada, Quality engineer |
| Category | Quality — test failure / supplier |
| Severity | High |
| Parts / lots | MS-250 seal kits, Precision Seals GmbH lot **PS-2608-B** (received 2026-08-04, 180 kits) |

## Description
4 more KP-250 pumps failed the hydrostatic test this week (cumulative 7 of 88 since 2026-08-10). Teardown of the failed seals shows **hairline cracks at the O-ring groove of the stationary seat gland** on all 7 — a pattern not seen before. Seals from the previous lot (PS-2606-A) show no cracks. Pumps that passed the test were shipped; the seals may crack later in service.

## Immediate actions
* Remaining kits of lot PS-2608-B (97 kits) placed on quality hold QH-2304.
* Supplier Precision Seals notified (SCAR-1112).
* Quality to identify shipped pumps built with lot PS-2608-B (build records from 2026-08-05 onward).

## Status
Open. **Risk: field failures on pumps shipped since 2026-08-05.**
